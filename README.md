## 🚀 Featured projects

### 🔐 [Crypto-Vigenere](https://github.com/ErmalZeqo/Crypto-vigenere)
Python implementation of classical encryption and cryptanalysis methods for the Vigenère cipher, including letter-frequency analysis, index of coincidence, mutual index of coincidence, and Pearson correlation.

**Technologies:** Python · Cryptanalysis · Classical cryptography

### 🔢 [DLP — Discrete Logarithm Problem](https://github.com/ErmalZeqo/DLP)
Implementation of number-theory and modular-arithmetic tools used in cryptography, leading to the Baby-Step Giant-Step algorithm for solving the discrete logarithm problem in a finite cyclic group.

**Technologies:** Python · Modular arithmetic · Number theory · Cryptography

### 🖥️ [CPU Simulator in C](https://github.com/ErmalZeqo/ErmalZeqo-Realisation-d-un-simulateur-de-CPU)
Educational CPU simulator covering hash tables, segmented memory, pseudo-assembly parsing, registers, addressing modes, instruction execution, and stack operations.

**Technologies:** C · Data structures · Computer architecture · Memory management

### ⚙️ [NACO — DevOps project](https://github.com/ErmalZeqo/DevOps)
Full-stack movie catalogue with a React frontend, FastAPI backend, PostgreSQL database, Docker-based development environment, Kubernetes deployment configuration, and GitLab CI/CD pipeline.

**Technologies:** React · Python · FastAPI · PostgreSQL · Docker · Kubernetes · GitLab CI/CD
